# batt 中文增强版

batt 是 Apple 芯片 MacBook 的菜单栏充电控制工具。你可以设定日常充电的上下限，也可以在出门前临时充满一次。后台服务负责执行限充，退出菜单栏应用后仍会继续工作。

**当前版本 `v0.8.0-zh.5`** 将菜单栏电池图标统一为白色。将指针停在图标上可查看充电状态，点开菜单可查看电量和充电上限。MagSafe 接头上的实体指示灯仍按所选灯控模式工作。

## 下载与安装

1. 在[中文增强版发布页](https://github.com/BuildWu19940706/battGUI-LED-zh/releases/tag/v0.8.0-zh.5)下载 `batt-v0.8.0-zh.5-macos-arm64.zip`。此包适用于 Apple 芯片 MacBook，应用最低系统版本为 macOS 13。可用功能取决于机型与固件。
2. 解压 ZIP，把 `batt.app` 拖入“应用程序”。升级时先退出旧菜单栏应用，再替换旧文件。
3. 打开 batt，点按菜单栏图标。首次使用选择“安装后台服务…”，从旧版升级选择“升级后台服务…”，然后按系统提示输入管理员密码。
4. 打开“自定义充电范围…”，核对上下限。系统首选语言为简体中文时，菜单会显示中文。

发布包使用本地临时签名（ad-hoc），未经 Apple 公证。需要校验下载文件时，将同一发布页的 `SHA256SUMS.txt` 与 ZIP 放在同一目录，在该目录运行以下命令。输出应为该文件名及 `OK`。

```sh
grep '  batt-v0.8.0-zh.5-macos-arm64.zip$' SHA256SUMS.txt | shasum -a 256 -c -
```

## 日常使用

| 想做什么 | 操作 |
| --- | --- |
| 让电量维持在设定范围 | 在“自定义充电范围…”中设置上下限。例如设置为 75%–80% 后，达到 80% 暂停，低于 75% 时恢复充电。 |
| 出门前充到 100% | 在“单次充电”一栏选择“临时充满一次”。完成或取消后，后台恢复日常限充。 |
| 查看充电状态 | 将指针停在白色菜单栏图标上，查看正在充电、已达上限或区间保持等文字提示。 |
| 调整 MagSafe 实体灯 | 支持的机型可在“高级设置 → MagSafe 指示灯”中选择模式。固件模式的已验证组合见中文指南。 |
| 卸载 | 在“高级设置”中选择“卸载后台服务…”，完成后退出 batt，再将应用移入废纸篓。 |
