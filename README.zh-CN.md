# batt 中文核心增强版

此源码合并自 [上游 batt](https://github.com/charlie0129/batt/commit/cab16c7abd7dcd99dd558b7f609072256b7e377c)，沿用 GPL-2.0 许可证。

## 使用

- 系统首选语言为简体中文时显示中文，其余语言显示英文。更改系统或应用语言后，退出菜单栏应用并重新打开。
- “自定义充电范围…”同时设置停止充电上限和恢复充电下限。例如设置为 **75%–80%**：达到 80% 暂停，低于 75% 后恢复。输入须为整数，满足 `10 ≤ 下限 < 上限 ≤ 100`。
- 上下限作为一个事务保存；保存或应用失败时恢复此前的设置。正在校准时不能改动范围。明确设置新范围会取消临时停用计时和单次充电任务。
- 菜单栏图标固定为白色。将指针停在图标上即可阅读充电状态，包括正在充电、已达上限、区间保持或暂停原因未确认。退出菜单栏应用后，后台仍继续控制充电。
- “临时充满一次”沿用上游逻辑，不覆盖平时的范围；完成或取消后交回原限制。校准、主动放电、临时停用等高级功能保留。

## MagSafe 实体指示灯

打开菜单栏的 **高级设置 → 控制 MagSafe 指示灯 → 启用**。后台根据当前充电模式和 Mac 提供的 MagSafe 接口显示此项；升级 macOS 后，后台会重新检测。若先前的后台已将灯控设为禁用，升级后请在菜单中手动启用。

在固件限充和 macOS 原生限充模式下，灯色跟随 macOS 报告的实际充电状态。以 75%–80% 的固件限充范围为例：

| 接通电源后的状态 | 实体灯 |
| --- | --- |
| 79% 重新插电，电池没有充电 | 绿色 |
| 79%，电池正在充电 | 橙色 |
| 80% 或更高，系统仍报告电池正在充电 | 橙色，系统报告充电停止后转绿 |

后台在维护循环中更新灯色，通常约 10 秒。传统直控和适配器模式按 batt 控制的充电开关或供电状态指示。选择“始终关闭”可熄灭指示灯，选择“停用”可交回系统控制。菜单栏的白色图标和悬停提示可用于查看充电状态。

## 安装与升级

1. 保留一份原版 `batt.app`，然后退出旧菜单栏应用，后台服务继续运行。
2. 解压交付 ZIP，将新的 `batt.app` 放入“应用程序”文件夹，替换原应用。
3. 打开应用，首次安装选择“安装后台服务…”，升级时选择“升级后台服务…”，在系统弹窗中输入管理员密码。新版 GUI 需要配套后台才能使用新增功能。
4. 等待约 10 秒，核对显示的上下限与自己的设置一致，再按上述菜单路径启用灯控。

交付包使用本地 ad-hoc 签名，未作 Apple Developer ID 公证。

## 回退原版

先取消正在执行的单次充电和校准任务，退出新版菜单栏应用。用备份的原版覆盖“应用程序”中的 `batt.app`，重新打开并选择升级后台服务，以切换回原版后台。安装流程保留 `/etc/batt.json`；不要删除该文件。回退后核对上下限仍为你希望的范围。新版的单次充电任务不能交给旧版继续执行。

## 从源码构建

需要 macOS、Xcode Command Line Tools 和 Go 1.24.5 或兼容工具链。所有命令在源码根目录执行，当前含空格和中文的项目路径可直接构建。

```sh
go mod download
go test ./...
go test -race ./pkg/daemon ./pkg/client ./pkg/config ./pkg/compatibility ./pkg/powerinfo
go vet ./...
make app VERSION=v0.10.0-zh.1-local
codesign --force --deep --sign - bin/batt.app
```

产物为 `bin/batt.app`。Go 与 Objective-C 共用 `pkg/gui/locales/zh-Hans.json`，资源嵌入二进制，并随 app 附带副本。

## 接口

- `PUT /charge-range` 接受 `{"upper":80,"lower":75}`。成功返回 201。后台会校验范围、充电模式及校准状态，保存或应用失败时尝试恢复原设置。
- `/compatibility` 的 `chargeRange` 表示是否支持同时设置上下限，`magSafeLED` 表示当前能否使用上游 MagSafe 灯控。macOS 原生模式只提供充电上限。
- `/telemetry` 的可选 `control` 字段包含充电目标、上下限、当前电量、状态原因及采样时间。旧后台缺少充电范围接口时，GUI 会提示升级。
