# v0.8.0-zh.2 固件灯控验证

## 实机证据

用户于 2026-11-01 在 M4（Mac16,12）、macOS 15.8.1、固件 mBoot-20457.1.29 上，以管理员 UID 0 运行独立灯控测试：

```json
{"matched":true,"readback":4,"requested":4,"step":"orange"}
{"matched":true,"readback":3,"requested":3,"step":"green"}
{"restoreSystem":"ok"}
```

用户确认亲眼看到指示灯变绿。此前 UID 501 的拒写结果仅说明普通用户权限不足。本次管理员测试未修改充电配置。

## 本版适配

- 仅对上述精确机型、系统、固件组合开放固件模式 LED 能力，且必须存在 LED 接口。其他组合继续保持未验证。
- 保持 firmware 充电后端；SleepHooks 仍为 false；不通过适配器断电实现绿灯。
- 灯控默认关闭。用户在“高级设置 → MagSafe 指示灯 → 启用（固件模式）”明确选择后，由已存在的后台状态机写入灯色。
- 已启用的偏好在匹配配置的重启中保留；升级系统或固件后未匹配配置时回到未验证状态。
- 配置读取仅在后台启动时执行；有超时和管道等待上限，失败不会使充电后台退出。不保存或记录序列号、UUID。
- 复用串行写入、读回确认、重复状态去重、睡眠/连接变化时交回系统，以及失败后的系统恢复。

## 检查

新增测试覆盖精确匹配、机型/系统/固件变化、缺失与错误硬件信息、充电后端隔离、默认关闭、重启保留偏好及双语菜单标题。新增用例先确认缺少功能时失败，再验证实现通过。

单独执行只读的本机配置集成检查，得到：

```text
model=Mac16,12 firmware=mBoot-20457.1.29 macOS=15.8.1 verifiedLED=true
```

该集成检查不写入硬件，默认自动测试不运行它。

独立代码审查无 Critical、Important 或 Minor 发现。最终完整测试、竞争检测、静态检查、构建和签名/解压结果随 `BUILD-INFO.txt` 交付。

## 验证边界

实际确认了管理员颜色写入、读回和可见绿灯；尚未声称完成真实睡眠、拔插及长时间运行的稳定性验证。状态转换及恢复路径有模拟测试覆盖。新版应用与后台的安装、升级和首次启用由用户操作；开发阶段没有直接替换运行中的服务或更改 75%–80% 范围。

旧的 v0.8.0-zh.1 安装包与源码包保留用于回退。
